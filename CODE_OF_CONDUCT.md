# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be welcoming, respectful and patient. People of all backgrounds and experience levels are welcome here.
- Give and accept constructive feedback gracefully. Focus on what's best for the project and the community.
- Harassment, insults, discriminatory language, personal attacks and publishing others' private information are not acceptable.

## Enforcement

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that violate this code. They may also temporarily or permanently ban contributors whose behaviour is inappropriate.

To report a problem, contact the maintainers privately on GitHub ([@xBrokkr](https://github.com/xBrokkr)). Reports are handled confidentially.
